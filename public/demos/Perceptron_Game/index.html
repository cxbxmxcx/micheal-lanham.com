The Perceptron Game

Set the weights by hand and watch a single perceptron try to fit the data. The simplest possible neural network, made visible.

The Perceptron Game

How to play

  1. Select one of the three training examples on the left. Its two values become the inputs, and its label becomes the expected output.
  2. To change a weight, click its box and type a value, or drag on the box.
  3. Watch the weighted sum, Output, Expected and Loss update as the weights change.
  4. Try to find one set of weights that brings the loss to 0.00 for all three examples.

You need a mouse or trackpad: the game area can’t be reached with the keyboard alone.

What the game shows

A single perceptron with three inputs. The top input is always 1.0, so its weight acts as the bias; the other two take the values of the training example you select. Each input is multiplied by its weight, the products are added, and the sum passes through a linear (purelin) activation. The panel on the right compares the result with the example’s label and shows the loss.

Built in Unity WebGL. Requires a desktop browser with WebGL enabled; the build is around 5 MB, so first load takes a moment.
